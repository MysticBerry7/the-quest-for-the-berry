Installation instructions:
I used VS Code for this project. Install that first and run the commands in the few following lines in the terminal.
Install Python: download the latest version of Python at python.org
If pip is not installed, install it at https://pypi.org/project/pip/
Install Unicorn: Use the command <python -m pip install django-unicorn> to install the python extension that allows for easier function calling on the front-end
